# Product Specifications

## Interface 1: General Planning Table
Headers: Themes (Aprendizagens Essenciais), Activities, Manual Page(s), Resources (Physical/Digital), Exercises (Physical/Digital), Registers.

## Interface 2: Classroom Presentation & Teacher Drawer
- Public Projection View: School Logo, Level, Group, Subject, Lesson Number(s), Date, Sumário, Atenção.
- Step-by-Step Guide & Attachments (Storage Uploads & External Links).
- Hideable Teacher Panel: Past/Future summaries & Hidden Class Notes Modal.

## Interface 3: Oral Evaluation Grid
- Student Self-Evaluation slider vs. Teacher Evaluation slider.
- Qualitative Scale (1-5): Posso Fazer Muito Melhor (1) to Fui Muito Bom (5).
